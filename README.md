# Social links profile

A responsive **Blog Preview Card** built with **HTML and CSS**.
This project focuses on creating a clean, accessible, and responsive Social component while practicing modern CSS layout techniques.

## 🎯 Project Goals

The main goal of this project was to practice:

* Structuring a webpage using semantic HTML
* Creating reusable card components
* Working with CSS layouts
* Managing spacing, typography, and alignment
* Creating responsive layouts
* Reproducing a design accurately from a reference
* Improving CSS fundamentals without relying on frameworks
